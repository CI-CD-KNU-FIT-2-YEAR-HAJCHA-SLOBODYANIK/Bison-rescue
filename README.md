# Bison-rescue

Тема: Ситуаційний моніторинг субпопуляцій зубра європейського в заказниках України (варіант «Порятунок зубрів»).

# **Як запустити проєкт? Гайд**

### 1. Встановлення залежностей (одноразово)

Перед першим запуском переконайтеся, що встановлені компілятор та утиліти (запускати в терміналі Linux):

```bash
sudo apt update && sudo apt install -y build-essential gcc make git
```

# Оновити репозиторій до останньої версії

git pull origin main

# Зібрати проєкт

make

# Приклад запуску проєкту (3 експедиції на 15 секунд)

./bison_rescue -n 3 -t 15

# Перегляд результатів (файл observations.csv)

cat results/observations.csv

# Очищення після збірки

make clean
